◉ Drone Orbit · Admin

Finish setup first

Open supabase-config.js and fill in your Supabase Project URL, publishable/anon key, and admin email. Do not paste a service-role key into this file.

Admin sign in

Only the configured admin email can manage products. Use the account created in Supabase Authentication.

Product manager

Add a product and click Publish. It will appear on the public Drone Orbit website as soon as the database save succeeds.

Published products

These products are currently stored in Supabase and visible on the storefront.
