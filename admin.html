Finish setup first

Open supabase-config.js and fill in your Supabase Project URL, publishable key, and admin email. Never use a service-role or secret key in this file.

Admin sign in

Only the configured admin emails can manage products. Use an account created in Supabase Authentication.

Product manager

Add a product and click Publish. It will appear on the public Drone Orbit website once the database save succeeds.

Published products

These products are stored in Supabase and managed here.
